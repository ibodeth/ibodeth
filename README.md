## Projects

### [Blink](https://github.com/ibodeth/Blink)
A local voice assistant that executes system commands, schedules timers, runs weather reports, and automates media playback based on voice commands.
- Picovoice Porcupine for local wake-word detection.
- Microsoft Edge TTS for voice feedback.
- Google Gemini to parse user intent into structured JSON commands.
- PyQt5 interface rendering a real-time waveform visualization.

### [PiCareerAgent](https://github.com/ibodeth/PiCareerAgent)
An autonomous career assistant pipeline that crawls job boards, filters postings, and tracks application lifecycles.
- Monitors target web boards using Firecrawl.
- Inspects IMAP mailboxes for recruiter replies.
- Evaluates role matches using LiteLLM.
- Telegram Bot interface for real-time notifications and statistics.

### [NoteMasterAI](https://github.com/ibodeth/NoteMasterAI)
An exam grading and assessment utility that uses object detection and language models to evaluate handwritten student answers.
- Python-based server and PyQt GUI.
- Flutter mobile client for exam scanning over Wi-Fi.
- Custom YOLOv8 model for question zone detection.
- Grades answers and generates feedback using the Google Gemini Vision API.

### [DeepPi-OLED](https://github.com/ibodeth/DeepPi-OLED)
A physical push-to-talk voice assistant client for Raspberry Pi that displays reasoning steps from local LLMs on an OLED screen.
- USB microphone and tactile button input on Raspberry Pi.
- Queries a local Ollama instance running DeepSeek-R1.
- Streams thinking tokens to an SSD1306 OLED screen over I2C.
